StudyMate AI is an AI-powered study assistant that helps students learn smarter and faster. Students can enter their class notes or any topic and generate summaries, quizzes, and flashcards using AI.

🚀 Features

* AI Summary: Convert lengthy notes into short and easy-to-understand summaries.
* AI Quiz: Generate 5 questions to test your knowledge.
* Flashcards: Create interactive flashcards for quick revision.
* API Key Settings: Add your AI API key to connect with the AI model.
* Loading Indicator: Shows progress while AI generates results.
* Responsive Design: Works on desktop, tablet, and mobile devices.
* Dark Mode: Switch between light and dark themes.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Gemini API
* Fetch API
* Async/Await

⚙️ How to Run

1. Clone this repository:
   git clone https://github.com/kartikshete/studymate-ai.git
   2. Open the project folder.
3. Open index.html in your browser.
4. Add your Gemini API key in the API settings.
5. Enter your notes or topic and generate your study material.

🔑 API Configuration

This project uses the Gemini API to generate AI-powered study content.

Get your API key from Google AI Studio and enter it in the application’s API settings.

Security Note: For a public production deployment, never expose a private API key in frontend JavaScript. Use a secure backend to handle API requests.

🎯 Project Objective

The main objective of StudyMate AI is to make studying easier, faster, and more interactive by using artificial intelligence to generate useful learning materials.
